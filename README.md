# AI时代机械结构设计工程师 · 个人发展计划

> **角色定位**：机械结构设计工程师 → 智能装备系统工程师  
> **计划周期**：2026-2030（5年战略规划）  
> **核心目标**：打造"机械 + 嵌入式 + AI"复合能力

---

## 项目概述

本仓库是一份面向机械结构设计工程师的系统性个人发展规划，涵盖：

- **行业分析**：AI时代机械设计领域的趋势、机遇与挑战
- **能力定义**：AI+机械复合型人才与智能装备系统专家的能力标准
- **进阶路线**：四大核心能力领域的分阶段成长路径
- **执行计划**：从年度目标到周计划的落地执行方案
- **跟踪工具**：进度追踪、复盘打卡与年度看板

## 核心特色

### 1. AI驱动的学习方式

不追求"从零学编程"，而是：

```
AI生成代码 → 读懂代码 → 修改扩展 → 形成知识体系
```

全程以 AI 工具（Cursor/Claude/Trae）为放大器。

### 2. 项目驱动的执行路径

每个阶段都有明确的交付物，以真实项目推动学习：

- **12周**：智能结构振动监测原型
- **24周**：SW API工具集 + 多传感器融合系统
- **36周**：边缘AI部署成功
- **24个月**：智能物料分拣系统 + 人形机器人行业调研
- **30个月**：人形机器人上半身原型

### 3. 量化追踪体系

- **每周打卡**：时间投入 × 任务完成 × 产出记录 × 自我复盘
- **月度看板**：年度目标进度追踪
- **季度回顾**：里程碑完成情况评估

## 使用指南

### 如果你是第一次接触

```
1. 先看 01-发展规划/总体/2026-2030_个人发展规划.md，了解整体蓝图
2. 再读 02-人才标准与进阶/，明确目标能力画像
3. 然后打开 01-发展规划/年度/2026/2026_阶段一执行指南.md 开始执行
4. 每周用 04-跟踪工具/每周打卡总表.html 进行进度追踪
```

### 推荐使用流程

| 频率 | 动作 | 工具 |
|------|------|------|
| **每日** | 编程学习 | Trae / Cursor |
| **每日** | 记录完成内容 | 打卡总表 |
| **每周日** | 复盘 + 规划下周 | 打卡总表 |
| **每月底** | 更新年度看板 | 打卡总表（年度看板页） |
| **每季度** | 对照计划评估进度 | 01-发展规划/总体/ |

## 风险提示

| 风险 | 应对策略 |
|------|---------|
| AI工具迭代过快 | 聚焦底层能力（Python/C/数据结构），工具可迁移 |
| 嵌入式学习曲线陡峭 | 项目驱动 + AI辅助，保持正反馈 |
| 学习动力下降 | 设置短期奖励，加入技术社群交流 |
| 工作生活打乱计划 | 预留弹性时间，从最近里程碑恢复 |
