## 02 | 机械结构设计行业 × AI

### 2.1 SOLIDWORKS 2026 — AI进入工程实践

SOLIDWORKS 2026 代表了机械设计领域AI落地的真实水平，其AI策略为**"垂直AI + 无感集成"**：

- **AI不从通用大模型出发**，而是基于达索系统40余年积累的工业知识库（材料属性、失效模式、制造约束、仿真边界条件）
- **不强调"AI"标签**——很多用户在用AI工具但自己不知道
- 目标是"释放创造力"，不是替代工程师

### 2.2 AI在机械结构设计的当前应用

#### 辅助式AI（已成熟，大量SOLIDWORKS功能）

| 功能 | 作用 | 效率提升 |
|------|------|---------|
| AI自动生成工程图 | 瞬间生成2D工程图（主视图/俯视图/剖面图/孔标注等） | **数小时→几秒** |
| 自动紧固件识别+装配 | 智能识别螺栓、螺母并自动装配（即使非Toolbox零件） | 大幅减少手动操作 |
| 指令预测器 | 绘制草图时预判下一步操作 | 减少操作步骤 |
| 拓扑优化 | AI驱动的拓扑优化，与制造工艺深度结合 | 更快得到最优结构 |
| 应力热点检测 | 自动识别FEA结果中的应力集中区域 | 快速定位薄弱点 |
| 工程图自动标注 | 尺寸公差自动标注 | 减少人工标注错误 |
| 视觉降噪器 | 深度学习渲染降噪 | 提升渲染速度 |
| 部分下载机制 | 大型装配体仅加载当前所需组件 | 解决上万零部件卡顿 |

#### 生成式AI设计（发展中）

- **MakeByMe**（达索系统免费工具）：用生成式AI设计书架、咖啡桌等，直接生成可制造3D模型
- **目标**：从导入实体自动创建参数化设计 → 自动生成工程图
- **成熟度**：2026年起步，预计2027-2028年进入实用阶段

### 2.3 与建筑结构设计的根本区别

| 维度 | 建筑结构设计 | 机械结构设计（你的方向） |
|------|------------|----------------------|
| 核心工具 | Revit, BIM, Bentley | **SolidWorks, CATIA, Inventor, UG/NX, Creo** |
| 设计对象 | 楼宇/桥梁/大跨度结构 | **产品/设备/零部件/机构** |
| AI重点 | BIM+AI、数字孪生 | **生成式设计、拓扑优化、DFM、FEA加速** |
| 嵌入式应用 | 结构健康监测（可选） | **电机控制、工业机器人、CNC、传感器** |
| 制造关联 | 建筑施工工艺 | **机加工/注塑/钣金/3D打印** |
| 仿真类型 | 风/地震/荷载 | **静力/疲劳/热/流体/运动学** |

### 2.4 AI对机械结构工程师的影响

**AI已能做到（机械领域）：**
- ✅ 常规结构计算与三维建模
- ✅ 自动出工程图
- ✅ 拓扑优化生成初始结构方案
- ✅ 紧固件自动识别与装配
- ✅ 标准件选型与校核
- ✅ 有限元分析自动化

**AI做不到（仍需人类）：**
- ❌ 产品概念设计与需求定义
- ❌ 多约束下的工程权衡（成本/工艺/性能/时间）
- ❌ 跨部门协调（设计→工艺→采购→生产→测试）
- ❌ 非标/异形件设计经验判断
- ❌ 失效模式分析与经验型决策
- ❌ 设计变更的连锁影响评估

> **结论**：AI替代的是"操作"，不是"判断"。机械设计工程师的核心价值从"建模+出图"转向"方案定义+系统决策"。

- **中国市场**：中小企业（"专精特新"）已普及3D设计，仿真/数据管理/协同是短板 → 下一个增长点
- **新兴领域**：医疗设备、新能源、低空经济、人形机器人 → 机械结构需求井喷

### 4.2 AI辅助嵌入式开发实战

**用Claude Code写STM32步进电机控制程序**：

```python
# 提示词示例（输入Claude Code）：
"用STM32F103 HAL库写步进电机控制程序：
- A4988驱动，1.8°步进角
- 加速/减速梯形曲线
- 编码器位置闭环
- 通过UART接收目标位置
- 用DMA定时器中断驱动，不阻塞主循环"

# Claude Code会自动生成：
# - GPIO/定时器/PWM/DMA初始化
# - 梯形加减速曲线算法
# - 编码器读取+位置PID
# - UART命令解析
```

**Python数据分析：振动频谱判断设备状态**：

```python
import pandas as pd
import numpy as np

# 读取传感器数据
df = pd.read_json("vibration_data.json")
# FFT频谱分析
fft = np.fft.fft(df['accel_z'].values)
freq = np.fft.fftfreq(len(fft), 1/100)  # 100Hz采样
# 提取主频 — 判断轴承/齿轮是否异常
peak_freq = freq[np.argmax(np.abs(fft[:50]))]
# 与正常频谱对比 → 判断设备健康状态
```
