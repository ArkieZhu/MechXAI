### W1实战：30分钟跑通第一个机械计算脚本

**目标**：写一个能用的Python脚本——输入梁的截面参数，输出弯曲应力校核结论。

**工具**：Trae国内版（免费，无需翻墙，中文原生）

打开Trae，新建文件 `beam_check.py`，在AI对话框输入：

```
帮写一个Python脚本，计算矩形截面梁的弯曲应力，
输入宽度高度载荷跨度，输出最大应力和安全系数
```

Trae Build模式生成代码后，点"应用"插入，运行：

```python
# 梁弯曲应力校核脚本（Trae AI生成，人工审核修改版）
def beam_bending_stress(width, height, load, span):
    """计算矩形截面梁的最大弯曲应力 (MPa)"""
    moment = load * span / 4           # 简支梁跨中弯矩 (N·mm)
    inertia = width * height**3 / 12    # 惯性矩 (mm⁴)
    c = height / 2                      # 中性轴到边缘距离
    stress = moment * c / inertia
    return stress

def safety_factor(yield_stress, actual_stress):
    """计算安全系数"""
    return yield_stress / actual_stress if actual_stress > 0 else float('inf')

# === 交互式主程序 ===
if __name__ == "__main__":
    print("矩形截面梁弯曲应力校核")
    b = float(input("截面宽度 b (mm): "))
    h = float(input("截面高度 h (mm): "))
    F = float(input("集中力 F (N): "))
    L = float(input("跨度 L (mm): "))
    sigma_y = float(input("屈服强度 σs (MPa): "))

    sigma = beam_bending_stress(b, h, F, L)
    n = safety_factor(sigma_y, sigma)

    print(f"\n最大弯曲应力: {sigma:.2f} MPa")
    print(f"安全系数: {n:.2f}")

    if n >= 1.5:
        print("✅ 安全")
    elif n >= 1.0:
        print("⚠️ 临界")
    else:
        print("❌ 不安全")
```

**我自己动手加了3个功能**（你也可以）：
1. 输入负数自动报错
2. 结果自动保存到 `result.txt`
3. 加了一个循环，可以连续计算多个截面

### 关键心得

**编程入门的关键不是"学语法"，而是"有项目、用AI、立即看到结果"**。Trae这样的AI IDE让机械工程师能跨过纯语法学习阶段，直接进入"用代码解决实际问题"的阶段。
